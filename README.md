# Tontonan — Android app

Watch thousands of live TV channels from around the world, with a program
guide, favorites and channel zapping — the Android companion to
[tontonan.online](https://tontonan.online).

## Download

**[Download the latest APK](https://github.com/faiqhayaza/tontonan-app/releases/latest/download/Tontonan.apk)**

That link always serves the newest release, so you never need to hunt for
an updated file.

## Install (sideload)

1. Open the download link above on your Android phone, tablet or
   Android TV and download `Tontonan.apk`.
2. Open the file. Android will ask you to allow installs from your
   browser — allow it for this install.
3. Tap **Install**. Done — the app appears in your launcher/app drawer.

Requires Android 6.0 or newer. Updates: download the newest APK from the
same link and install it over the old one — your favorites and settings
are kept.

This repository hosts the official release binaries only.
